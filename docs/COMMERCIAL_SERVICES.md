- Deploy for your company or paying clients (hosting, configuration, hardening).

## What you may not do

## Getting help

Need someone to deploy this stack or merge features into an existing Laravel project?

- **Community:** open a GitHub issue in this repository (bugs, questions).
- **Professional services:** the **maintainer** may be available for deployment, integration, and custom modules on a project basis — use the issue tracker with label `professional-services` or the contact listed in the repository profile.

Independent agencies may offer the same services if they comply with the CBL restrictions above.
