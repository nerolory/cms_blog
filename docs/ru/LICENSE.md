## Суть

| Разрешено | Запрещено |
|-----------|-----------|
| Развёртывание для себя и клиентов (в т.ч. коммерческих) | Продажа продукта как **отдельного коммерческого товара** (шаблон, turnkey-копия, SaaS-перепродажа без существенной доработки) |
| Интеграция модулей в другие системы | Удаление текста лицензии из исходников |
| Платные и **бесплатные** услуги по установке, настройке, интеграции | Выдача себя за официального представителя автора без согласия |
| Внутреннее использование в компании | Нарушение лицензий Laravel, FastAPI и других зависимостей |

## Сторонние компоненты

Laravel, Filament, FastAPI и npm/composer-зависимости распространяются **по своим лицензиям** (преимущественно MIT). CBL регулирует **исходный код и документацию этого репозитория**.

## Услуги интеграции

Лицензия **не запрещает** коммерческое развёртывание и интеграцию «под ключ». Подробнее: [COMMERCIAL_SERVICES.md](COMMERCIAL_SERVICES.md).

Автор проекта также может оказывать услуги по развёртыванию и встраиванию функционала — см. тот же документ.
